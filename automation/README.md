# 内网退货自动处理助手 使用说明

本目录提供一套运行在内网 Edge 浏览器上下文中的**单文件退货自动化脚本**，利用当前已登录页面的同源 `XMLHttpRequest` 自动通过瑞数 WAF 签名，无需安装任何第三方客户端、无需连接打印控件出纸，也不弹任何 jBox 阻断框。

## 一、文件说明

| 文件 / 目录 | 用途 |
|---|---|
| `edge-extension/` | **离线 Edge 本地扩展文件夹（最推荐）**：拷入内网在 `edge://extensions` 加载一次，以后打开内网网页自动出现右下角「退货助手」悬浮按钮，无需按 F12 |
| `edge-extension.zip` | 上述扩展目录的便携压缩包（约 30 KB，方便单文件拷贝到内网后解压使用） |
| `return_auto.js` | 单文件版本：也可直接通过 Edge 代码片段（Snippets）或 F12 控制台粘贴运行 |
| `test_return_auto.js` | 开发机离线自测套件（无需内网环境，模拟全部后端接口、扩展结构与异常边界） |
| `README.md` | 本使用说明 |

## 二、内网安装与启动方式（任选其一，均无需联网）

### 方式 1：安装离线 Edge 本地扩展（最推荐，一次加载永久免 F12）
1. 将 `edge-extension/` 文件夹（或先拷 `edge-extension.zip` 到内网再右键全部解压缩）放到内网电脑一个固定位置（例如 `D:\工具\edge-extension\`，**安装后不要删除该文件夹**）。
2. 打开内网 Edge 浏览器，在地址栏输入 **`edge://extensions`** 回车进入「扩展管理」页面。
3. 打开左侧（或右上角）的 **「开发人员模式」** 开关。
4. 点击页面顶部的 **「加载解压缩的扩展」** 按钮，选中刚刚放好的 `edge-extension` 文件夹（包含 `manifest.json` 的那一层目录）点「选择文件夹」。
5. 安装完成！建议顺手点浏览器右上角拼图图标，把 **「内网退货自动处理助手」** 点亮固定到工具栏。
6. **日常使用**：正常登录内网投递系统（`/portal/a` 或任意 `/delivery-web/` 页面），页面右下角会自动出现一个蓝色的 **「退货助手」** 悬浮按钮（也可随时点浏览器右上角扩展图标打开或收起面板），完全不遮挡原业务界面。

### 方式 2：Edge 代码片段（无需装扩展，F12 一键运行）
1. 在已登录的内网页面按 `F12` 打开开发者工具。
2. 切换到顶部 **源代码（Sources）** -> 左侧 **代码片段（Snippets）** -> 点击 **新建代码片段**（命名为 `return_auto`）。
3. 将 `return_auto.js` 全部内容粘贴进去并按 `Ctrl + S` 保存。
4. 以后每次需要批量退货时，右键该代码片段点击 **运行**（或按 `Ctrl + Enter`），页面右上角即弹出悬浮控制面板。

### 方式 3：控制台直接粘贴（临时快速启动）
1. 在已登录的内网页面按 `F12` 打开 **控制台（Console）**。
2. 复制 `return_auto.js` 全部内容粘贴进去回车即可弹出面板。
   - 若新版 Edge 首次粘贴拦截并提示英文警示，先在控制台输入 `allow pasting` 回车，再粘贴脚本即可。

## 三、首次上机实操步骤（安全四步法）

1. **确认自动识别的账号与手机号**（所有修改会自动记忆在浏览器本地）
   - 面板打开后会自动从内网「下段扫描」页读取当前登录账号的 **归班投递员**（如 `张三-7100xxxxxxx`）与系统隐藏绑定的 **道段**（如 `T01`，已收进高级参数里，平时**完全不用手动填写或关心“道段”**；换其他同事账号登录时也会自动切换）。
   - 主面板只需核对 **归班投递员** 和 **补打固定手机号**（默认 `13000000000`，须为 1 开头 11 位数字）；若页面刚切换登录，可点顶部 **「重新识别账号」** 刷新。
   - 打印模板（默认 `SD_GN_KB_MD`，多产品混跑可改 `AUTO`）和下段道段均收在折叠的「高级参数与安全选项」中，一般保持默认即可。

2. **演练模式预检（默认已勾选）**
   - 保持右上角徽标为橙色 **「演练模式」**。
   - 直接从 Excel 选中单号列复制粘贴到文本框（或将 `.csv`/`.txt` 文件直接拖入文本框），先放 **2～5 单** 点击 **「开始执行」**。
   - 演练模式下脚本**只执行只读查询，绝不调用任何写入提交接口**，可安全核对每个单号被判定为正常下段、撤单补打还是异常跳过。

3. **小批正式验证**
   - 取消勾选 **「演练模式」**（徽标变为红色 **「正式模式」**）。
   - 先用 **5～10 单** 点击 **「开始执行」** 并在二次确认框中点确定，跑完后去系统页面核对是否已全部流转至归班交接。

4. **大批量运行与异常处理**
   - 验证通过后可直接粘贴或导入 **200～500 单**（脚本按高级设置中的每批单数自动分批提交，默认每批 50 单、间隔 150ms，避开前端 200 件上限与服务端超时）。
   - 运行中可随时点击 **「暂停 / 继续」** 或 **「中止」**。
   - 结束后点击 **「导出 CSV 报表」**（带 UTF-8 BOM 且单号防科学计数法，Excel 打开不乱码不丢精度）。
   - 如个别单号失败，点击 **「载入失败单」** 可一键回填重跑；如果只有某一步需要补跑（例如 C 已成功、仅补跑 D），在阶段复选框里只勾选对应阶段即可。

## 四、内置自动分流与安全护栏

| 场景 | 脚本自动行为 |
|---|---|
| 正常可下段邮件 | `A1预检` -> `A2批量下段` -> `C退回妥投(signType=130)` -> `D归班交接` |
| 客户撤单邮件（提示“详情单补打”） | `A1识别` -> `B1查单` -> `B2缺号/脱敏号自动补固定手机号` -> `B4调用print3标记打印(零出纸)` -> `A1回流重扫` -> `A2` -> `C` -> `D` |
| 无收寄信息（`noPostingInfo`）/ 投递库不存在 / 稽核件 / 红字拦截 | 自动标记 `SKIPPED` 并记录原因，跳过不阻塞整批 |
| 代收货款件（`codAmount > 0` 或 `ifPay = 1`） | 默认安全跳过（可在高级参数中调整），避免误操作金额校验 |
| 一票多件未凑齐 | 下段前自动检测主单件数，未凑齐的安全跳过 |
| 重复运行遇到“已下段”邮件 | 默认直接送入 C 阶段继续退回妥投（可在高级参数中开关） |
| 归班交接防误操作 | D1 查出该投递员今日全部任务后，**仅与本次任务成功单号严格求交集**，绝不误交接同投递员的其他正常包裹；若后端延迟未立即查到，会自动等待 1.2 秒重试一次 |
| 登录态过期 | 检测到 401/403 或返回登录页 HTML 时立即安全停机，刷新页面重登录后继续 |

## 五、离线回归自测（开发机）

在项目根目录执行：

```powershell
node automation/test_return_auto.js
```

测试脚本会加载真实交付的 `automation/return_auto.js`，通过内存模拟后端完整校验 10 项核心用例（单号解析与 CSV 往返导入、手机号校验、模板解码、全链路 11 个接口字段契约、演练模式零写入、AUTO 多模板分组、会话失效中断、暂停/恢复/中止及 D 阶段严格交集）。
